# Project skills

Project-specific skills belong in this directory.

Initial skills to create or install deliberately:

- Odoo 19 source verification
- Capability catalogue ingestion and verification
- Discovery rule authoring and testing
- Deployment manifest validation
- Odoo provisioning handler development
- Hebrew RTL and accessibility review
- Cross-tenant security review

Every `SKILL.md` requires valid front matter with a non-empty `name` and `description`. Skills must not contain credentials, customer data or unverified technical claims.
